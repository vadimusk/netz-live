# Roadmap

Ideas here are deliberately not commitments or a release schedule. They are directions worth revisiting after the current interface has had time to settle.

## Energy-flow graph

Explore an optional visualisation that presents the grid as a living flow graph rather than a set of tables: generation sources feed demand, storage, and neighbouring countries through animated paths whose direction and intensity reflect the current power flows.

The graph should complement the compact overview, not replace it. It must remain legible without animation, respect reduced-motion preferences, work well with touch input, and preserve the calm visual language of the existing site.
